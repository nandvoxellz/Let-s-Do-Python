1. Mulai dari **Day 01** dan ikuti urutan angkanya.
2. Tiap Day punya file bernomor (`01_...`, `02_...`) — baca sesuai urutan itu.
3. Ada folder practice di `Python/Project`? Coba kerjain sendiri dulu sebelum liat solusinya.
